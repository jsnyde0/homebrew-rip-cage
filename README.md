# homebrew-rip-cage

Homebrew tap for [rip-cage](https://github.com/jsnyde0/rip-cage) — Docker sandbox for Claude Code agents with a safety stack.

## Install

```bash
brew install jsnyde0/rip-cage/rip-cage
```

## What it installs

- `rc` CLI on PATH
- `jq` and `tmux` as dependencies
- zsh and bash completions

Docker (or OrbStack) is required separately.
